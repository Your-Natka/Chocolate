🍫 Chocolate — Лендинг для магазину солодощів

Цей проект — це адаптивна вебсторінка, створена з використанням **HTML5** та **CSS3**, яка демонструє стильний дизайн сайту для шоколадного бренду або магазину.

## 🚀 Технології

- 💻 **HTML5** — семантична розмітка
- 🎨 **CSS3** — стилізація, включаючи медіа-запити для адаптивності
- 📱 **Responsive Design** — підтримка мобільних пристроїв і планшетів
- 📂 **Файлова структура**: простий проект без фреймворків або збирачів


📱 Адаптивність
Сайт адаптований під такі розміри екранів:

✅ Мобільні телефони (до 480px)

✅ Планшети (481px – 768px)

✅ Десктопи (понад 768px)
